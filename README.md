# Fanatix

An Android ticket resale marketplace where users can sell tickets they can no longer use at fair prices, instead of the inflated markups common on other resale platforms.

Built as a four-person team project for CSE 3310 at the University of Texas at Arlington.

## Purpose

This app is built to help ticket holders and buyers:

* Resell unused tickets without paying inflated reseller prices.
* Browse tickets listed by other users.
* List a ticket for sale.
* Create an account and sign in.
* View and manage a personal profile.

## Tech Stack

* **Language:** [Kotlin](https://kotlinlang.org/) for the Android app.
* **IDE:** [Android Studio](https://developer.android.com/studio) for development and testing.
* **Build System:** [Gradle](https://gradle.org/) for building and managing the project.

## Running the Project

1. Clone or download this repository.
2. Open Android Studio and select **File > Open**.
3. Choose the project folder and let Gradle finish syncing.
4. Run the app on an Android emulator or a connected Android device.
